# Boccia Strategy Board（ボッチャ戦術分析ボード）

Webブラウザで動くボッチャの盤面再現・暫定得点・戦術検討アプリです。iPad Safari のタッチ操作を最優先に設計しています。

**アプリを開く：https://isthd.github.io/Boccia-Strategy-Board/**

---

## 使い方

### 画面構成
- **上部**：盤面名（タップで名前変更）／自由配置・試合再現の切替／規則版の選択（通常版・フレンドリー版）／保存一覧・書出・共有・ヘルプ（狭い画面ではアイコンのみ）
- **ツール**：目的別に「球（選択・ジャック・赤・青）」「作図（矢印・目標点・計測・注釈）」「消す（削除）」の3グループ。下の帯に、選択中のツールと次にする操作を表示します
- **中央**：実寸のコート（左上に暫定得点、右上に審判パドル、右下で拡大・縮小・ジャック周辺・全体表示、倍率×1.0以下では左下に球まわりの拡大小窓）
- **情報パネル**（iPad横向きは右側、縦向きは下側で折りたたみ可）：盤面／球／作戦／局面／試合／設定
- **下部**：戻す・やり直す、1投を記録（試合中）、局面を保存、A/B比較、初期化（右端）

### 基本操作
- 球の色を選んでコートを**タップすると1球追加**します。球を**ドラッグすると移動**します（球ツールのままでも、球の上から指を動かせば移動）。
- **2本指でピンチズーム・パン**、余白を1本指でドラッグしてパン。ページ全体はスクロールしません。
- 起動時はセンタークロスを中心に**×2.0**で表示します。コート全体を見るときは右下の「全体表示」を使います。
- 倍率が**×1.0以下**になると、左下にジャック周辺（ジャックから1.5m以内の球）の**拡大小窓**を表示します。小窓をタップするとその範囲へ拡大します。
- **審判パドル**：距離の判定（どちらの球がジャックに近いか）が変わるたびに、コート右上に赤／青のパドルを数秒表示します。判定が入れ替わるとパドルが裏返り、次に投げるサイドも表示します。同距離のときは赤青2本を掲げます。エンドの採点中は、得点したサイドのパドルを出したままにします。
- 球を選ぶと「球」タブで **x・y座標（cm）を数値入力**でき、**1cm／5cm単位の移動ボタン**も使えます。タッチしにくい球は一覧から選べます。
- 追加・移動・削除・状態変更はすべて**戻す／やり直す**の対象です。削除と初期化の前には確認を出します。
- キーボード：Ctrl+Z／Ctrl+Shift+Z（Ctrl+Y）、Delete、矢印キー（1cm、Shift で5cm）、V/J/R/B/M/A/T でツール切替、Esc で選択解除。

### 自由配置モード（初期表示）
- 投球順を強制せずにジャック・赤・青を配置します。7球目以降を追加すると「非公式の自由配置」と表示します。
- 配置を変えるたびに距離順位と**暫定得点（このまま終了した場合）**を再計算し、得点の根拠（得点球と距離）を一覧で示します。
- 「局面」タブで**分岐（A案→B案）・局面の保存・A/B比較**（暫定得点、ジャックの移動距離、未配置球、接触候補、重なり）ができます。
- 「作戦」タブで目標点・矢印・注釈を作図します。戦術タグ（近づける／相手球を押す／ジャックを動かす／ブロックする）や戦術メモ（狙い・成功時の配置・失敗時のリスク・相手の残り球）を付けられます。

### 試合再現モード
1. 「試合再現」→ 規則版・試合形式（個人／ペア／チーム）・競技クラス・エンド数・持ち時間（分単位、0.5分刻み）・選手名を設定します。
2. **ジャック投球**：担当ボックスが表示されます。ジャックを置いて「有効」か「ファウル」を記録します。
3. **カラー球**：次に投げるサイドと、その根拠になる条文が表示されます。球を置き、当たって動いた球も置き直してから「**この状態を1投として記録**」を押します（結果：有効／アウト／反則除去、エリア外の球のアウト化、ジャックのクロス再配置、所要時間、メモ）。**ドラッグしただけでは球数も持ち時間も減りません。**
4. 両サイドが投げ終わる（またはBNP申告）と採点画面になります。手動での得点修正（理由付き）、ペナルティボール（通常版のみ）を入れて「エンド得点を確定」します。
5. 規定エンド終了時に同点なら、通常版は**追加エンド**、フレンドリー版は**ファイナルショット**を行います。
6. 投球履歴は任意の時点を表示でき、「ここから分岐」で自由配置の新しい盤面になります（元の試合は消えません）。

### 保存・書き出し
- 操作のたびに端末内（IndexedDB）へ**自動保存**され、リロードしても続きから再開できます。データを外部へ送信することはありません。
- 「保存一覧」で開く・複製・名前変更・削除・検索ができます。
- 「書出・共有」から次の形式で書き出せます。
  - **PNG・SVG**：盤面の画像。タイトル・得点・球番号・寸法・作図・距離線を表示するか選べます。
  - **JSON**：書き出しと読み込みの両方に対応。読み込み時に形式・座標範囲・ID重複・版番号を検証します。
- iPad では共有シートを使い、使えないブラウザではダウンロードします。
